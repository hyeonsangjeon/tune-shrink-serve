# 0. 실험 설정 — 모델, 데이터, 프롬프트, 채점, 장비

**한국어** | [English](00_setup_en.md)

이 문서는 ①~④ 모든 결과에 공통인 조건을 적습니다. 각 결과 문서에는 그 실험에만 해당하는 조건이 따로 있습니다.

## 한 문단 요약

KT의 공개 모델 Mi:dm 2.0 Base(11.5B)에 한국 보건의료 국가시험 기출문제(KorMedMCQA)를 LoRA로 학습시켰습니다. 2012~2020년 문제로 학습하고 2021년 문제로 중간 점검만 했습니다. 2022~2024년 문제 3,009개로 최종 정답률을 쟀습니다. 같은 모델을 TorchAO로 INT4까지 줄이고 vLLM으로 서빙해 속도와 비용도 같은 H100 한 장에서 쟀습니다.

## 데이터

[`sean0042/KorMedMCQA`](https://huggingface.co/datasets/sean0042/KorMedMCQA)는 의사·간호사·약사·치과의사 국가시험의 5지선다 기출문제입니다(커밋 `79efd6f9`, CC BY-NC 2.0). 데이터셋은 레포에 넣지 않고 실행할 때 내려받습니다. 형식을 보여 주려고 아래에 학습용 문항 하나만 출처와 함께 옮겼습니다.

| 쓰임 | HF split | 시험 연도 | 문항 수 | 이 레포 설정 이름 |
|---|---|---|---|---|
| 학습 | `train` | 2012~2020 | 3,401 | `train` |
| 중간 점검 | `dev` | 2021 | 1,059 | `selection_dev` |
| 최종 평가 | `test` | 2022~2024 | 3,009 | `final_holdout` |

- 세 묶음은 시험 연도가 겹치지 않습니다. 로더는 문항 ID나 연도가 겹치면 바로 멈춥니다(`kormedmcqa.assert_disjoint`).
- 2022~2024년 문제는 **모델마다 한 번만** 쟀습니다. 같은 결과 파일이 있으면 평가 스크립트가 다시 재지 않습니다(`eval_vllm.py`).
- 정답률을 읽는 기준은 두 가지입니다. 찍으면 20%, 국가시험 합격 참고선은 60%입니다.

### 한 문항은 이렇게 생겼습니다

간호사 국가시험 2019년 1교시 1번입니다(학습용 `train` split). 출처는 KorMedMCQA(arXiv 2403.01469)이고 CC BY-NC 2.0입니다.

| 필드 | 값 |
|---|---|
| `subject` · `year` · `period` · `q_number` | `nurse` · 2019 · 1 · 1 |
| `question` | 항원에 대한 IgE 항체가 생성된 후 히스타민과 같은 매개물을 분비하여 발생하는 과민반응은? |
| `A` ~ `E` | 천식 / 접촉피부염 / 전신홍반루푸스 / 장기이식 거부반응 / ABO 부적합 수혈반응 |
| `answer` | `1` (보기 번호 1~5) |

데이터셋에는 풀이를 담는 `cot` 칸도 있지만, 이번 학습과 평가에는 쓰지 않았습니다. 학습에는 이런 문항 3,401개를 썼습니다.

## 프롬프트와 정답 형식

Mi:dm의 채팅 템플릿을 그대로 씁니다. 이 템플릿은 모든 요청 앞에 KT의 고정 시스템 문구(약 450토큰)와 오늘 날짜를 붙입니다. 날짜가 바뀌면 프롬프트가 바뀌므로 `21 Nov 2026`으로 고정했습니다(설정 파일의 `template_kwargs.date_string`).

```text
[시스템]  당신은 한국 보건의료 국가시험 문제를 푸는 어시스턴트입니다. 보기 중 정답의 번호 하나만 숫자로 출력하세요. 설명은 쓰지 마세요.
[사용자]  다음은 간호사 국가시험 문제입니다. 보기 중 정답의 번호 하나만 숫자로 답하세요.

          항원에 대한 IgE 항체가 생성된 후 히스타민과 같은 매개물을 분비하여 발생하는 과민반응은?
          1. 천식
          2. 접촉피부염
          3. 전신홍반루푸스
          4. 장기이식 거부반응
          5. ABO 부적합 수혈반응
[모델]    1
```

이 블록은 「한 문항은 이렇게 생겼습니다」의 예시 문항이 프롬프트가 된 모습입니다. 실제 요청에는 이 앞에 Mi:dm 템플릿의 고정 시스템 문구와 날짜가 붙습니다.

- 프롬프트 길이는 2022~2024년 문제에서 평균 654토큰입니다(vLLM이 센 값). 학습 최대 길이는 1,024토큰으로 두었고 학습 로그에 이 길이를 넘어 잘린 문항은 없었습니다.
- 학습할 때는 정답 번호와 턴을 닫는 토큰 `<|eot_id|>`에만 손실을 겁니다. 예시 문항이라면 모델이 배우는 부분은 `1<|eot_id|>` 두 토큰뿐이고, 프롬프트 부분에는 손실을 걸지 않습니다.
- 생성은 greedy입니다. 모델이 기본으로 들고 있는 샘플링 설정(temperature 0.8, top_p 0.7)은 끄고 `<|eot_id|>`와 `<|end_of_text|>`에서 멈춥니다.

## 채점

- 모델 답에서 ①~⑤, 1~5, A~E 중 처음 나온 것을 고른 번호로 봅니다. 고를 수 없으면 오답으로 셉니다. 이번 측정에서 자체 GPU 모델의 답 중 번호를 못 읽은 것은 0개였습니다. 매니지드 API 모델은 [4. 비용](04_cost.md#-매니지드-api와-비교--slm-대-api)에 따로 적었습니다.
- 정답률 옆의 범위는 95% 신뢰구간(Wilson)입니다. 3,009문항이면 대략 ±1.7%p입니다.
- 두 모델을 비교할 때는 **같은 문항끼리 짝지어** McNemar 정확 검정을 씁니다. 한쪽만 맞힌 문항 수를 세어 차이가 우연인지 봅니다. 신뢰구간만 겹쳐 보는 것보다 작은 차이를 잡습니다.

## 이 실험 전체가 말할 수 없는 것

- **seed는 42 하나입니다.** 2022~2024년 문제의 숫자는 모두 seed 42로 한 번 학습한 모델에서 나왔습니다. 나중에 Unsloth 학습만 seed 43으로 한 번 더 돌려 2021년 문제로 재 보니 0.9~1.5%p 달랐습니다([5. 점수 올리기](05_recipe_sweep.md)). seed에 따라 점수가 얼마나 달라지는지 제대로 알려면 더 여러 번 돌려야 합니다.
- **GPU는 H100 한 종류입니다.** 다른 GPU에서는 특히 INT4 속도가 달라질 수 있습니다.
- **기출문제는 공개 자료입니다.** 튜닝 전 모델이 사전학습 때 이 문제들을 봤는지는 확인할 수 없습니다. 튜닝 전 정답률이 이미 63%인 것도 그 영향일 수 있습니다.
- **의료 조언에 쓰는 모델이 아닙니다.** 시험 문제를 고르는 능력만 쟀습니다.
