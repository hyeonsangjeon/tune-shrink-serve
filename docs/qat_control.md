# QAT 대조 실험: 가짜 양자화 덕인가, 더 학습한 덕인가

발표와 별개로 돌린 실험입니다. 이 문서의 「계획」 절은 실행 전에 적었습니다(2026-11-17 05:31 UTC). 결과는 실행이 끝난 뒤 아래에 덧붙입니다. 계획 절은 결과를 보고 고치지 않습니다.

## 질문

INT4 QAT([`steps/3_int4_qat.py`](../steps/3_int4_qat.py))는 PTQ와 비교해 두 가지가 다릅니다.

1. 학습하는 동안 가중치를 INT4로 반올림했다가 되돌려 씁니다(가짜 양자화). 모델이 반올림 오차를 겪으며 가중치를 고칩니다.
2. 같은 학습 문항 3,401개로 600 step(약 2.8번)을 더 학습합니다.

발표 실행에서 QAT는 PTQ보다 +0.2%p(p=0.67), 같은 코드로 다시 학습한 실행에서는 +1.0%p(p=0.02)였습니다. QAT가 나을 때 그게 1번 덕인지 2번 덕인지는 지금까지의 실행으로 가를 수 없습니다. 이 실험은 2번만 하고 1번은 하지 않은 모델을 만들어 비교합니다.

## 계획 (실행 전에 적음)

### 무엇을 돌리나

출발점은 셋 다 발표의 BF16 LoRA 모델([`HyeonSang/Midm-2.0-KorMedMCQA`](https://huggingface.co/HyeonSang/Midm-2.0-KorMedMCQA), 2022~2024년 문제 72.3%)입니다.

| 이름 | 하는 일 | seed |
|---|---|---|
| P | 바로 INT4로 바꿈 (PTQ, `steps/2_int4_ptq.py`) | — |
| Q | 가짜 양자화를 넣고 600 step 학습 → INT4 (지금의 QAT) | 42, 43, 44 |
| X | 가짜 양자화 없이 같은 600 step 학습 → BF16 → INT4 (`--no-fake-quant`) | 42, 43, 44 |

X는 INT4로 바꾸기 전의 BF16 모델도 채점합니다. "더 학습만 한 BF16 모델"이 처음 BF16 LoRA 모델보다 나아졌는지를 봅니다.

**Q와 X 사이에서 바뀌는 것은 가짜 양자화 하나입니다.** 같게 둔 것:

- 학습하는 가중치: 출력층(lm_head)을 뺀 모든 선형층, 약 105억 개. 작은 모델로 두 경로가 같은 가중치를 학습하는지 확인했습니다(학습하는 가중치 이름과 개수가 같음).
- 학습 설정: 학습률 1e-5, 600 step, 배치 4 × accumulation 4, 8비트 AdamW, warmup 3%, gradient checkpointing.
- 학습 문항: 1단계와 같은 3,401개(2012~2020년).
- INT4 설정: 2단계와 같음(`Int4WeightOnlyConfig`, group 128).
- 채점: `steps/4_evaluate.py`, 2022~2024년 3,009문항, 모델마다 한 번.
- GPU와 소프트웨어: H100 NVL 1장, 11-16~17 재학습과 같은 환경.

**seed는 학습 문항을 섞는 순서만 바꿉니다.** 같은 seed의 Q와 X는 같은 순서로 문항을 봅니다. 그래서 seed마다 Q와 X를 짝지어 비교합니다.

### 비교와 판정 기준

seed s마다 세 값을 계산합니다(정답률, %p).

| 비교 | 식 | 묻는 것 |
|---|---|---|
| ① 가짜 양자화 효과 | Q_s − X_s(INT4) | 반올림을 겪으며 학습한 것이 따로 도움이 됐나 |
| ② 추가 학습 효과 (INT4) | X_s(INT4) − P | 더 학습만 해도 INT4 점수가 오르나 |
| ③ 추가 학습 효과 (BF16) | X_s(BF16) − 72.3 | 더 학습만 해도 BF16 점수가 오르나 |

판정은 세 비교에 같은 규칙을 씁니다.

- **효과 있음:** 세 seed 모두 같은 방향이고, 평균 차이가 0.5%p 이상
- **효과 없음:** 평균 차이의 크기가 0.2%p 이하
- **그 밖:** 가르지 못함

0.5%p는 같은 3,009문항에서 두 모델을 비교할 때 문항에서 오는 흔들림의 크기입니다. 두 모델 중 한쪽만 맞힌 문항이 약 200개일 때 차이의 표준편차가 √200 / 3,009 ≈ 0.47%p입니다. 짝마다 McNemar p도 함께 적지만 판정에는 쓰지 않습니다. McNemar는 학습을 다시 할 때의 흔들림을 넣지 않기 때문입니다.

### 예상 (실행 전에 적음)

- ① 평균 +0.3~0.8%p. 가짜 양자화가 조금 도움이 된다는 예상입니다. 판정은 "가르지 못함"과 "효과 있음"의 경계쯤일 것으로 봅니다.
- ② 평균 0 근처. 이미 맞춘 모델을 학습률 1e-5로 더 학습해도 INT4 점수는 거의 안 바뀔 것으로 봅니다.
- ③ 평균 0 근처이거나 조금 내려감.

다음 결과가 나오면 이 예상이 틀린 것입니다.

- ① 평균이 0.2%p 이하: QAT가 PTQ보다 나았던 만큼은 추가 학습으로 설명됩니다.
- ②가 ①만큼 크거나 더 큼: QAT의 이득은 가짜 양자화보다 추가 학습 쪽에서 왔습니다.

### 알려진 한계

- **출발점은 BF16 LoRA 모델 하나로 고정입니다.** LoRA를 다시 학습할 때의 흔들림은 이 실험에 들어가지 않습니다. 앞의 재학습에서 QAT−PTQ가 +0.2%p에서 +1.0%p로 바뀐 데는 그 흔들림도 들어 있었습니다.
- **같은 seed로도 GPU 계산이 매번 조금 달라 결과가 바이트 단위로 같지 않습니다**(11-16~17 재학습에서 확인). 이 흔들림도 seed 사이 차이에 함께 들어갑니다.
- **seed 3개로는 흔들림의 크기를 대략만 압니다.**
- **2022~2024년 문제로 설정을 고르지 않습니다.** 모든 설정은 발표 값 그대로이고, 새 모델은 모델마다 한 번만 채점합니다.
- **학습률, step 수, 학습하는 층은 바꿔 보지 않습니다.** 이 설정에서의 답만 나옵니다.

### 순서, 중단 조건, 비용

1. 작은 확인: X를 5 step만 학습하고 2021년 문제 50개로 채점. 학습하는 가중치 수가 QAT 실행 기록(10,468,982,784개)과 다르면 본 실행을 하지 않습니다.
2. P를 만들고 채점.
3. seed 42, 43, 44 순서로 X(BF16 채점, INT4 채점) → Q(INT4 채점). seed마다 짝이 하나씩 끝나므로, 도중에 멈춰도 끝난 짝까지는 비교할 수 있습니다.

예상 시간은 약 11~12시간이고, H100 NVL $6.98/h로 약 $80입니다. 14시간(약 $100)을 넘으면 멈추고, 그때까지 끝난 짝으로 보고합니다. 끝나면 VM을 끕니다(deallocate).

결과 파일은 [`quantization/results/kormedmcqa_midm/qat_control/`](../quantization/results/kormedmcqa_midm/qat_control/)에 둡니다. 문항별 답만 담고 문제 본문은 담지 않습니다.

## 계획 추가 (2026-11-17 09:15 UTC, seed 42 결과만 보고 적음)

seed 42 한 짝이 끝난 뒤, seed 43과 44의 결과를 보기 전에 적었습니다.

**seed 45, 46 두 짝을 더 돌립니다.** seed 43과 44의 결과와 상관없이 돌립니다.

이유는 같은 설정끼리의 흔들림입니다. seed 42 QAT는 같은 설정으로 세 번 학습했고, 점수가 69.69%(발표), 70.09%(11-16~17 재학습), 69.96%(이번)였습니다. 같은 설정끼리 0.4%p까지 차이가 나는데, 이 폭이 판정 기준 0.5%p와 비슷합니다. seed 3개로는 「가르지 못함」이 나올 가능성이 커서 seed를 늘립니다.

- **처음 판정은 바꾸지 않습니다.** 위의 판정 규칙을 seed 42, 43, 44에 적용한 결과를 먼저 보고합니다.
- **seed 5개 결과는 따로 적습니다.** 같은 규칙을 5개에 적용합니다(다섯 seed 모두 같은 방향, 평균 0.5%p 이상). seed마다의 차이와 평균도 함께 적습니다. 두 결과가 다르면 다르다고 적습니다.
- 돌리는 방법은 위와 같습니다. seed마다 X(BF16 채점, INT4 채점) → Q(INT4 채점) 순서입니다.
- **시간과 비용:** 짝 하나에 약 2.9시간이 걸려 약 5.8시간, 약 $40이 늘어납니다. 상한은 VM을 켠 때부터 17시간(약 $120)으로 바꿉니다. 그 시간을 넘으면 그때까지 끝난 짝으로 보고합니다.

**바로잡음 (2026-11-17 14:25 UTC, seed 44까지 본 뒤).** 위 「이유」에 적은 세 점수 중 70.09%는 같은 설정이 아니었습니다. 11-16~17 재학습은 BF16 LoRA 모델부터 새로 학습했으므로 QAT의 출발 모델이 다릅니다(그 실행의 69.69%짜리 이어 학습 실행도 마찬가지). 출발 모델과 seed가 모두 같은 실행은 발표 QAT(69.69%)와 이번 seed 42 QAT(69.96%) 두 개이고, 차이는 0.27%p입니다. 추가를 결정한 근거는 적어 둔 것보다 약했습니다. seed 45, 46을 돌리는 결정과 위의 규칙은 바꾸지 않습니다.

### 본 것

- INT4 정답률은 가짜 양자화를 넣고 학습한 쪽(Q)이 넣지 않은 쪽(X)보다 세 seed 모두 0.53~0.56%p 높았습니다.
- 가짜 양자화 없이 600 step을 더 학습한 모델을 INT4로 바꾸면 P와 거의 같았습니다(seed 4개에서 −0.03~−0.30%p).
- 그 모델의 BF16 정답률은 네 seed 모두 출발점보다 낮았습니다(−0.27~−0.56%p).
- 이 설정에서는 X(INT4)와 P가 거의 같아서, Q − X(+0.55%p)와 Q − P(+0.42%p)가 비슷합니다. QAT가 PTQ보다 높게 나온 만큼은 추가 학습으로 설명되지 않습니다.
- 600 step 학습 시간은 X가 37.6~37.7분, Q가 101.1분입니다. 가짜 양자화를 넣으면 학습이 약 2.7배 느렸습니다.
- 학습 loss는 Q가 조금 높았습니다. 600 step 동안의 평균 loss가 Q는 1.336~1.344, X는 1.317~1.320입니다.

### 그럴 법한 이유

가짜 양자화를 넣으면 모델이 학습하는 동안 INT4 반올림 오차를 겪고, 그 오차가 덜 해로운 쪽으로 가중치를 옮깁니다. 이것이 QAT의 원래 설명이고, ①은 이 설명과 맞습니다. 다만 무엇이 바뀌었는지(어느 층, 어떤 문항)는 재지 않았습니다. ③에서 BF16 정답률이 내려간 것은 같은 3,401문항을 약 2.8번 더 본 탓일 수 있습니다. ③은 판정 기준에 못 미쳤고, 이 원인도 따로 재지 않았습니다.

### 이 결과로 말할 수 없는 것

- **①의 「효과 있음」은 기준을 겨우 넘었습니다.** 평균 +0.55%p로 기준 0.5%p보다 0.05%p 큽니다. seed마다의 McNemar p는 0.28~0.30이어서, 짝 하나만 보면 문항에서 오는 흔들림과 구별되지 않습니다. 판정은 세 seed가 모두 같은 방향이라는 데 기대고 있습니다.
- **seed를 늘려도 이 불확실성은 줄지 않습니다.** ①의 seed 사이 차이는 0.03%p로, 문항에서 오는 흔들림(약 0.47%p)보다 훨씬 작습니다. 모든 seed를 같은 3,009문항으로 채점했으므로, 세 seed가 같은 방향인 것은 다시 학습할 때의 흔들림이 작다는 뜻입니다. 다른 문제로 채점해도 같은 차이가 난다는 뜻은 아닙니다.
- **출발점이 BF16 LoRA 모델 하나입니다.** LoRA부터 다시 학습한 11-16~17 실행에서 QAT − PTQ는 +1.0%p였고, 이번 평균은 +0.42%p입니다. LoRA를 다시 학습할 때의 흔들림은 이 실험에 들어 있지 않습니다.
- **QAT가 PTQ보다 낫다고는 이 실험으로도 말할 수 없습니다.** 참고로 계산한 Q − P의 평균 +0.42%p는 같은 규칙으로 「가르지 못함」입니다. 이 실험으로 말할 수 있는 것은 "QAT가 PTQ보다 높게 나온 만큼은 추가 학습 덕이 아니다"까지입니다.
- **학습률, step 수, 학습하는 층은 하나씩만 봤습니다**(1e-5, 600 step, lm_head를 뺀 모든 선형층).
- **문항별 파일이 없어 다시 분석할 수 없는 것이 있습니다.** 가짜 양자화가 어떤 문항에서 도움이 됐는지, seed 45의 짝 비교는 계산할 수 없습니다.

### 기록과 다시 돌리기

기록은 [`quantization/results/kormedmcqa_midm/qat_control/`](../quantization/results/kormedmcqa_midm/qat_control/)에 있습니다.

| 파일 | 내용 |
|---|---|
| `run_log.txt` | 단계마다 시작 시각과 걸린 시간, 정답률과 맞힌 문항 수, 학습 기록(seed 42~44) |
| `paired_printout.txt` | seed 42~44 짝 비교(한쪽만 맞힌 문항 수, McNemar p), P와 발표 PTQ의 답 비교 |
| `eval_printouts.txt` | 모델마다 `steps/4_evaluate.py`가 출력한 결과(직군별 정답률 포함) |
| `train_printouts.txt` | 20 step마다 loss, 학습이 끝날 때의 기록 |
| `summary.json` | 위 네 파일과 발표의 A·PTQ 채점 파일로 만든 요약과 판정 |

`summary.json`은 [`scripts/qat_control_summary.py`](../scripts/qat_control_summary.py)가 만듭니다. 이 스크립트는 기록끼리 맞는지도 봅니다. 맞힌 문항 수의 차이가 한쪽만 맞힌 문항 수의 차이와 같은지, 출력된 p가 다시 계산한 p와 같은지 확인합니다. CI는 `--check`로 `summary.json`이 기록과 같은지 확인합니다.

다시 돌리려면 출발점 모델을 `outputs/0_start`에 두고 seed마다 아래를 실행합니다(H100 NVL에서 seed 하나에 약 2.9시간).

```bash
hf download HyeonSang/Midm-2.0-KorMedMCQA --local-dir outputs/0_start
python steps/2_int4_ptq.py --src outputs/0_start --out outputs/qc_p && python steps/4_evaluate.py outputs/qc_p
python steps/3_int4_qat.py --no-fake-quant --seed 42 --src outputs/0_start --out outputs/qc_x42
python steps/4_evaluate.py outputs/qc_x42_bf16 && python steps/4_evaluate.py outputs/qc_x42
python steps/3_int4_qat.py --seed 42 --src outputs/0_start --out outputs/qc_q42 && python steps/4_evaluate.py outputs/qc_q42
```

채점 파일(`outputs/4_eval_*_test.json`)은 단계가 끝날 때마다 지워지지 않는 디스크로 옮겨 두십시오. 이번 실행은 이 파일을 지워지는 디스크에 두었다가 잃었습니다.
